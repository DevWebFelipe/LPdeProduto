# LP de Produto

Uma landing page responsiva para divulgação de um produto fictício. Projeto voltado à prática de estrutura semântica HTML e estilização CSS com foco em responsividade.

## 🔗 Visualização

Acesse o projeto online: [LPdeProduto](https://devwebfelipe.github.io/LPdeProduto/)

## 📱 Responsivo

✅ Desktop  
✅ Mobile

## 🚀 Tecnologias

- HTML5
- CSS3
- Flexbox
- Media Queries

## 🧑‍💻 Como utilizar

1. Clone o repositório:
git clone https://github.com/DevWebFelipe/LPdeProduto.git

2. Abra o `index.html` no seu navegador.
